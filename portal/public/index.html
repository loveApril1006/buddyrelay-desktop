QUESTIONS & ANSWERS
开始之前，
你可能想了解。
如何开始使用？
注册并登录后，联系管理员充值积分，在模型广场选择模型即可开始对话。也可以创建 API Key 接入自己的工具。
积分如何扣除？
按模型定价计费，调用前预扣预计上限，完成后按上游返回的用量结算。上游未返回有效用量时按预扣上限计费，详情可在控制台查看。
缓存命中如何收费？
各模型单独配置有效期和命中收费比例。在非流式、随机程度为 0 的文本请求中主动开启缓存后，重复请求可能命中缓存。
可以使用哪些客户端？
支持配置 OpenAI 兼容地址的客户端可接入本站 Chat Completions 接口。具体模型以模型广场已开放列表为准。

DEVELOPER GUIDE
接入 BuddyRelay API
使用 OpenAI 兼容的 Chat Completions 接口。先创建 API Key，再从模型广场复制已开放的模型 ID。
计费与重试
每次请求可传入 Idempotency-Key。重复的非流式请求返回已有结果，避免重复扣费。调用前预扣，完成后按有效 usage 结算。流式中断的请求在后台人工核对后结算。
回答缓存
为请求设置 cache 为 true、temperature 为 0、stream 为 false。缓存按用户隔离，仅适用于管理员开启缓存的模型和无工具调用的文本请求。
