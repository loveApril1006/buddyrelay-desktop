常见问题
查看接口文档

      

        
如何开始使用？
注册并登录后联系管理员充值，在模型广场选择已开放的模型。网页对话可直接使用账户，外部客户端需要创建 API 密钥。

        
外部客户端要填哪些参数？
选择 OpenAI 兼容接口，填写接入文档中的基础地址、账户 API 密钥和模型广场中的准确模型 ID。

        
积分什么时候扣除？
网关会在发起请求前暂扣预计上限，并按上游返回的用量结算。上游未返回有效用量时按暂扣上限计费，详情可在用量日志查看。

        
哪些请求可以命中回答缓存？
模型已配置缓存时，主动启用缓存的非流式请求需要将随机程度设为 0，并且不附带工具定义。同一账户在有效期内发送相同请求才可能命中。

        
怎样确认模型能完成我的任务？
先用实际任务做少量试用。对照所需的参数和输入长度，检查结果和用量日志，再决定是否接入业务。

        
怎么充值和查看余额？
在控制台打开账户充值页，复制你的账户邮箱并联系管理员。到账后可在积分流水中查询。

DEVELOPER GUIDE
接入 BuddyRelay API
使用 OpenAI 兼容的 Chat Completions 接口。先创建 API Key，再从模型广场复制已开放的模型 ID。
计费与重试
每次请求可传入 Idempotency-Key。重复的非流式请求返回已有结果，避免重复扣费。调用前预扣，完成后按有效 usage 结算。流式中断的请求在后台人工核对后结算。
回答缓存
为请求设置 cache 为 true、temperature 为 0、stream 为 false。缓存按用户隔离，仅适用于管理员开启缓存的模型和无工具调用的文本请求。
